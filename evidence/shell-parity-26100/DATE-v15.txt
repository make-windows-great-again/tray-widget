ShellPanels v15 — Date и контейнер независимых карточек
05.11.2026, Windows 11 26100.9711, 2560x1600, 150%, монитор 240 Гц

Сделано
- Date входит справа за 167 мс по профилю. Наблюдаемая часть движения в записи:
  150.00..150.06 мс; Windows 150.06..154.17 мс. В v14 было около 225 мс.
- Календарь сворачивается плавно. Footer с Focus остаётся на месте, Header
  движется вниз, уведомления получают освободившуюся высоту. Материал живой.
- Вынесен CardSection / Host::SetSections / ExpandSection / SectionExpanded.
  Date и отдельный пример используют один контейнер из статической ShellPanels.lib.
  Header, Body, Footer — реальные элементы Windows.UI.Xaml. Flexible Body делит
  остаток высоты; fixed Body имеет размер DIP и независимое состояние раскрытия.
  Одно окно и один XAML Island; отдельного HWND/DLL на карточку нет.
- Состояние сохраняется после Hide/Show. Разворот анимации отменяет прежнее
  завершение. Фокус скрываемого Body возвращается в Header/Footer того же XamlRoot.
- Материал теперь отступает от внешней рамки. На контрольной вертикальной грани
  Date начало материала X=600 в кадре и у Windows, и у C++; раньше C++ было X=598.
- Исправлены кнопки Focus (+/- 24 DIP, значки 12 DIP, заполненный Play,
  ширина запуска 72 DIP), рамки малых кнопок и высота заголовка Notifications.
- Тень сохраняет ресурсы при изменении размера. Удалён эксперимент с постоянными
  expression-анимациями XAML Visual.Size: этот facade не дал нужную тень в Island.
  Используется SizeChanged с обновлением существующей маски и SpriteVisual.
- Ни VPN-провайдеры, ни сетевые настройки не менялись. Меню батареи по-прежнему
  имеет общий отступ от taskbar, а не ошибочную привязку к Y клика из Windows.

Измерения и ограничения
- Сворачивание: Windows 220.83 мс, C++ 225.00 мс в светлой/тёмной теме.
- Раскрытие: Windows 220.83 мс, C++ 204.17 мс (светлая), 220.83 мс (тёмная).
  Это пороговое измерение по границе с допуском 2 px, а не точное время Timeline.
  Максимальный интервал захвата внутри этих переходов 8.33..12.50 мс.
- Вертикальная геометрия Date пока отличается на 3 физических пикселя:
  начало материала нижней карточки Windows 826 / C++ 823; при сворачивании
  Windows 1360 / C++ 1357. Полное совпадение контура/траектории не заявляется.
- Высота Body анимируется зависимой XAML-анимацией 300 мс. Пересчёт layout
  выполняется в UI thread; это сознательный компромисс ради реальных размеров,
  обрезки, фокуса и hit testing. Контролы и эффект материала на кадрах не создаются.
  Постоянных таймеров нет. AnimationsEnabled=false / animate=false дают конечную
  геометрию сразу. Запрошенные 240 fps записи не являются доказательством render fps.
- Пример по клавише 4 показывает API компоновки и стандартные OS controls;
  он не заявлен как полный набор оформленных Win11-контролов для приложений.
- Остаются уведомления (иконки приложений, группы, действия), точные цвета текста,
  тени и базовые линии, Calendar UIA, неактивирующий Language, live theme всех
  дочерних контролов, детали Quick Settings, смешанный DPI и малые рабочие области.
  Смена разрешения/рабочей области в потребителе требует Host::Reposition.
- Переподключение к существующему Explorer (F05) — отдельный незакрытый дефект.

Доставка и проверка рабочего приложения
Новый EXE подключён к Explorer; активны mode=2, applied=2, size=88x48 DIP,
error=0, attach=0. Повторно проявился F05 (0x80070490) при замене EXE.
Один контролируемый перезапуск Explorer восстановил работу; открытые папки
восстановлены. Это обход, а не исправление F05. Сохранены журнал ошибки,
date-v15-deployment-before-recovery.json и date-v15-shell-recovery.json.
Закреплённый patch DLL и layout.ini побайтно прежние (SHA256 проверены).
Новый EXE проверен физическими кликами по tray-widget; после записи выбран Date.
Клик по виджету управляет новой схемой Date.
Экспортированный SDK отдельно скомпилирован без заголовков source/, его EXE
прошёл UIA RangeValue, живое обновление модели без обратной команды, физическое
нажатие локальной плитки и открытие/закрытие четырёх меню. Зависимости — системные.

Контрольные пиксели боковой грани (нейтральный фон, X=598 Y=1000 внутри кадра):
light: Windows 97 / C++ 98; dark: Windows 90 / C++ 96. Материал X=600:
light 234 / 235, dark 45 / 46. См. date-v15-edge-samples.csv. Разница тени
в тёмной теме сохраняется; это не глобальная сертификация цветов.
