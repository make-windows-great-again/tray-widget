НЕ ПОДТВЕРЖДЕНО В ЭТОЙ СРЕДЕ

Причина первоначального attachResult=0x80004005 установлена точно:
  station=WinSta0
  desktop=CodexSandboxDesktop-c741f62ad2d480f1bc57cb5992cccfa3
  input-desktop=Default
  shell-pid=0 taskbar=not-found
В старом коде общий E_FAIL подставлялся после отказа Shell_NotifyIcon.
До загрузки патча дело не доходило; это не подтверждение дефекта DLL.

После исправления запуск --controls --show, --attach и --diagnose на таком
рабочем столе возвращает 3 с описанием причины до создания окна/singleton.
Сырые данные: desktop-preflight-current.json. В --standalone готовый EXE
сохраняет полноценную работу; клиентские тесты повторно прошли.

Полная проверка оболочки запущена повторно: она останавливается с тем же
точным объяснением. В live-results-current.txt остаётся FAIL: подключение
DLL к настоящему Explorer ещё не проверено. После сообщения пользователя
о выдаче прав доступ проверен повторно; изолированный desktop сохранился.
Запрос штатного запуска вне sandbox отклонён инструментом:
  sandbox_approval=false
Рабочий стол и настройки изоляции автоматически не переключались.

Для подключения откройте Start-Framework.cmd или готовый EXE из Проводника
на обычном рабочем столе Windows. Программа --diagnose проверяет контекст.
Команда для обычной пользовательской сессии:
  powershell -ExecutionPolicy Bypass -File tools\Test-Live.ps1 -CrashTest

CopyFromScreen для собственного окна также вернул The handle is invalid.
Снимки получить не удалось. Запись прежней попытки захвата отдельно
сохранена в capture-limitation.txt. Текущий client-results-current.txt
содержит успешный прогон без повторного захвата недоступного экрана.

Осталась визуальная матрица на реальном рабочем столе: 100/125/150/200% DPI,
перенос между мониторами, High Contrast, отключённая прозрачность, сравнение
материала при закрытии на разных фонах и UI Automation bounds кнопки Explorer.
Арифметические тесты DPI и переключение Light/Dark в собственном окне
не выдаются за прохождение этой матрицы. Потемнение из старого аудита не
считается исправленным для всех тем и фонов только на основании новых тестов.
